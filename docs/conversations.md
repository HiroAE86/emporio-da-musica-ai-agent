# Domínio: exemplos de conversa

O entregável requer de 3 a 5 conversas em `.md`, `.txt` ou imagem, cobrindo cenários variados. Pelo menos uma deve demonstrar consulta não trivial a dados ou aplicação de uma política. Os exemplos serão incluídos após existir um agente executável e as respostas puderem ser verificadas pelas fontes.

## Cenários sugeridos

1. Listar violões disponíveis por até R$ 1.000, consultando catálogo e disponibilidade.
2. Informar endereço da loja, se a fonte de contexto trouxer esse dado.
3. Consultar o preço do Takamine GD20 no catálogo.
4. Explicar se uma compra por arrependimento pode ser devolvida, consultando o manual.

Não inventar conteúdo para preencher lacunas nas fontes.
